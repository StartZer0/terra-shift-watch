# Implementation verification

November 5, 2026 (Baku). These are engineering checks on the local build, not independent environmental accuracy benchmarks.

## Delivered local application

React/TypeScript, Cesium globe, Python/FastAPI and an isolated raster worker. Muse Wonder (`muse-wonder-1.0`, maximum reasoning) supplies bounded interpretations; Meta `sam-3.1` supplies actual masks. Codex wrote the application. No claim is made that Muse Code generated it.

The application supports global search, coordinate entry and globe picking; metric square resizing and drawn polygons with editable corner coordinates; multiple selected themes with switchable result layers; inclusive annual ranges and event windows; calibrated source adapters; quality masking and equal-area measurements; common-support change and descriptive trends; forest/terrain references; weather context; SAM point selection; before/after overlays; timeline playback; MP4/GIF; and evidence ZIP exports containing JSON, CSV, GeoJSON and derived GeoTIFFs. Scientific limitations remain explicit in results.

Downloaded exports are explicit copies and are separate from the server lifecycle. The usage ledger retains spending/request metadata only.

## Remaining limits

There is no independent labeled-scene benchmark establishing segmentation or change-class accuracy. The tool measures broad changes; desertification, permanent deforestation, erosion and disaster causation are not diagnosed from index differences. Radar measures matched-orbit backscatter changes, not confirmed flooding. Shorelines are not tide-normalized. Landsat sensor differences remain. Event-mode weather is seasonal context, not event attribution. Data coverage and cloud conditions can prevent a valid comparison.

This is a local, single-active-analysis application. Public hosting, multi-user authentication, submission recording and hackathon submission have not been performed. Existing local credentials are sufficient for local operation; additional hosting credentials are only needed when a deployment target is chosen.

Place-name search uses Cesium's [official geocoder](https://cesium.com/learn/ion-sdk/ref-doc/IonGeocoderService.html), with city/coordinate fallback. Result attribution is retained by the globe. Match names and coordinates should be checked by the user before running an analysis.

## SAM 3.1 investigation and annual integration

The original empty 2020 result was reproduced with the unchanged source image, concept `water` and compact mask encoding. Its request completed normally, but the delta, done and final text were all empty; the official parser produced zero records and zero diagnostics. The unchanged 2000 control returned 470 characters and one box/mask pair. This establishes an empty concept result at the service boundary, rather than loss of a valid mask in our parser. It does not establish why the internal detector missed the water.

A positive point on the identical 2020 image produced a water mask. A fixed policy using spectral component locations, boxes and positive/negative points then returned three masks, about 869.25 ha before full-history common-support restriction. Its same-image spectral agreement was approximately 92.13%; this is guided agreement, not independent accuracy. The policy was fixed before that test and does not search prompt variants for the highest agreement. At most four spectral components of at least sixteen pixels are prompted, using an eight-pixel box margin; omitted objects can remain undetected. No spectral mask is substituted for the returned SAM mask.

New optical runs segment every available year for each selected concept, with one optional geometric-guidance attempt only after a genuinely empty concept response. Water/Coasts share water requests, and Greening/Forests share vegetation requests. Forest SAM measurements are restricted to a dated tree-cover mask. Source acquisitions, object bounds, model scores, guidance provenance, attempts and request IDs accompany the results. Unrecognized/malformed model text, invalid masks and provider errors are separate from empty results. Streaming also handles a valid completed response when text deltas are absent; this hardening did not cause the original 2020 miss.

The existing 2000–2020 report was processed without re-downloading the Landsat history. Forty-two concept/image checks plus nineteen guidance attempts produced usable water masks for all 21 yearly periods; eight water periods required guidance. Vegetation had 16 usable yearly masks, eleven guided and five empty. The latter do not support an endpoint forest SAM change result. Water/Coasts share requests and do not double this call count. The SAM refresh, including one Muse interpretation, took 142.37 seconds on this run; this is not a universal performance benchmark.

SAM's fixed representative-image support covers 99.6638% of the selected square. On that support, the water mask area changed from approximately 2,365.18 to 867.46 ha, with approximately 7.35 ha gained and 1,505.07 ha lost. These are distinct from the seasonal spectral measurements and are not ground-truth estimates. All missing or failed masks remain gaps, not zero-area observations. Annual masks, SAM gain/loss images, counts, areas and provenance remain temporary derivatives under the same run cleanup policy. Muse now receives the scoped SAM summaries and their exact metric keys, and explains method agreement/disagreement without treating guided masks as independent validation.

The interface exposes the SAM chart, metrics, source-method toggle, yearly mask inspector, confidence disclosure and mask playback. A generic user-selected object is kept separate from concept-history playback. Annual frames are segmented independently; SAM video propagation is not claimed across year-long discontinuities. MP4/GIF exports remain the satellite-image history; the evidence ZIP includes SAM images and measurement JSON.
